# Meww Bot

A playful greeting bot with the supplied cat artwork. Choose English or Hindi, then try the greeting chips or type `hi` or `hello`. Both greetings reply `Hello`. Other messages get a grumpy response. Hover the cat's eyes or type in the message box to make the cat look annoyed. Use **New chat** to reset the conversation.

## Run it

1. Install Node.js.
2. Run `npm start` in this folder.
3. Open [http://localhost:3000](http://localhost:3000).

No API key or extra packages are needed.
